# Support

## Bug Reports

If you believe you found a bug in CSS Tree Inspector, please open a GitHub Issue and use the Bug Report template.

Include:

- Steps to reproduce the problem
- Chrome version
- CSS Tree Inspector version
- Operating system
- Relevant screenshots or sample output when helpful

Please remove passwords, tokens, private data, or other sensitive information before posting.

## Feature Requests

Feature requests are also welcome through GitHub Issues using the Feature Request template.

## Security Issues

Please do not report security vulnerabilities in a public GitHub Issue.

Use GitHub's private vulnerability reporting feature for this repository instead.
