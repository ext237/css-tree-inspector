# Installation

1. Open the [GitHub Releases page](https://github.com/ext237/css-tree-inspector/releases).
2. Download the newest `css-tree-inspector-x.y.z.zip` file under **Assets**.
3. Extract the ZIP to a permanent folder. Do not select the ZIP itself in Chrome.
4. Open `chrome://extensions` in Chrome.
5. Enable **Developer mode**.
6. Click **Load unpacked** and select the extracted folder containing `manifest.json`.
7. Open or reload Chrome DevTools, select **Elements**, and open **CSS Tree Inspector**.

After installing an update or modifying extension files, click **Reload** on the extension card and reopen DevTools.
