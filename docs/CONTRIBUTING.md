# Contributing

Thank you for helping improve CSS Tree Inspector.

1. Open an issue describing a bug or proposed change.
2. Create a focused branch and keep source code readable and unminified.
3. Preserve the extension's local-only privacy model and minimal-permissions policy.
4. Run `powershell -ExecutionPolicy Bypass -File .\tests\static-tests.ps1`.
5. Manually load the unpacked extension and test both DevTools themes.
6. Submit a pull request explaining the behavior and verification performed.

Please do not add analytics, remote services, frameworks, host permissions, or generated build artifacts without discussing the tradeoff first.
