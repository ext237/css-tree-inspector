# Privacy Policy

**Effective date:** August 7, 2026

CSS Tree Inspector performs all analysis locally inside the user's browser. It does not collect, transmit, sell, share, or remotely store personal information, inspected DOM content, computed CSS, browsing activity, or usage analytics.

The extension does not use a server, account, cloud service, advertising system, or tracking technology. It does not access cookies, browser history, local storage, session storage, authentication tokens, or network traffic. Structured element attributes omit `value` attributes; input and select values are not captured as structured text. Authored textarea text is preserved as requested for whitespace-sensitive content. The JSON report's exact `outerHTML` field can also contain values or sensitive information already present in the selected element's HTML markup. Users should review and redact reports before sharing them. Reports remain in the local DevTools session unless the user explicitly copies them to the clipboard.

CSS Tree Inspector requests no extension permissions or host permissions. Chrome provides access to the currently inspected page through its DevTools extension APIs.

If this privacy policy changes, the updated policy will be published with the project and its effective date will be revised.
